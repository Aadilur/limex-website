# Kalpurush

`kalpurush.ttf` is Kalpurush 0.258 by Tanbin Islam Siyam, developed under the Avro Font Development Project. It is distributed under the SIL Open Font License, Version 1.0. The font file contains the license metadata; the license and FAQ are also available at <https://scripts.sil.org/OFL>.

The font is bundled so generated editable Word documents can preserve Bengali text on systems where a Bengali font is not already installed.
